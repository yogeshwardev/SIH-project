# Local mobile builds

`CraftLink-debug.apk` is generated by `npm run android:debug` and copied here
for device handoff. APK binaries are intentionally ignored by Git; every CI run
also publishes the same installable package as the `CraftLink-android-debug`
artifact.

The checked-in debug build targets the Android Emulator host at
`http://10.0.2.2:8000/api`. Build with a deployed HTTPS `VITE_API_BASE` before
installing on physical beneficiary devices.
